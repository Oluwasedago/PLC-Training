# Chapter 3: PLC Hardware and Supporting Modules

## Overview
An Automation Engineer must be part Electrician. This chapter focuses on the physical components of the S7-1200 and S7-1500 families and how they interact with field devices.

## Learning Objectives
* **CPU Selection:** Choosing a processor based on Work Memory, Bit performance, and Retentive memory.
* **I/O Modules:** Digital (DI/DQ) for discrete signals and Analog (AI/AQ) for continuous variables.
* **Specialty Modules:** High-Speed Counters (HSC) for encoders and Technology Modules (TM) for Motion Control.

## Engineering Best Practices
* **Power Budgeting:** Calculating the current draw on the backplane bus.
* **Expansion Limits:** Understanding how many modules can be added to a single CPU rack before requiring ET200 distributed I/O.
