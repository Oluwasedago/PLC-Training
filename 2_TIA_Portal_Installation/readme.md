# Chapter 2: TIA Portal Installation and Environment Setup

## Overview
Totally Integrated Automation (TIA) Portal is a heavy-resource engineering framework. This chapter ensures your workstation is optimized to prevent software crashes and communication bottlenecks.

## Learning Objectives
* **Software Tiers:** Differences between Step 7 Basic (S7-1200) and Professional (S7-1500/300/400).
* **Side-by-Side Installation:** How to manage multiple versions (V16, V17, V18, V19, V20) on one machine.
* **License Management:** Using the Automation License Manager (ALM) for Floating vs. Trial licenses.

## System Requirements & Troubleshooting
* **Hardware:** SSD is mandatory; 16GB RAM is the absolute minimum for stable operation.
* **Common Fixes:** Enabling .NET Framework 3.5/4.8 in Windows Features and adjusting User Account Control (UAC) settings.
