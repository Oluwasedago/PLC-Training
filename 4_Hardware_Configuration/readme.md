# Chapter 4: TIA Portal Hardware Configuration

## Overview
Configuration is the bridge between the physical and digital world. This chapter covers the "Device View" where we define the hardware rack, network parameters, and internal CPU properties.

## Learning Objectives
* **The Device Catalog:** Correctly matching Article Numbers (MLFBs) and Firmware versions.
* **Networking:** Configuring Industrial Ethernet (PROFINET) interfaces and Subnet masks.
* **CPU Properties:** Setting up Retentive memory, Protection levels, and Web Server access.

## Critical Configuration Steps
* **System/Clock Memory:** Enabling the byte that provides 1Hz, 2Hz, and 10Hz clock pulses for logic.
* **PROFINET Device Name:** Understanding why the "Device Name" is more important than the IP address in PROFINET networks.
