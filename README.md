## 📖 Course Roadmap
This training is structured into nine core chapters. Each directory contains specific documentation, code samples, and technical guides.

### [Chapter 1: Introduction to PLC](./1_Introduction/)
*Fundamentals of Industrial Control, the History of PLCs, and the IEC 61131-3 standard.*

### [Chapter 2: TIA Portal Installation](./2_TIA_Portal_Installation)
*Setting up your engineering environment, software requirements, and license management.*

### [Chapter 3: PLC Hardware and Supporting Modules](./3_PLC_Hardware/)
*Understanding S7-1200/1500 architectures, signal modules, and industrial wiring.*

### [Chapter 4: TIA Portal Hardware Configuration](./4_Hardware_Configuration/)
*Building the digital twin of your system, IP addressing, and CPU property optimization.*

### [Chapter 5: PLC Simulation](./5_PLC_Simulation/)
*Testing logic without hardware using S7-PLCSIM and virtual monitoring.*

### [Chapter 6: PLC Tags and Data Types](./6_Tags_and_Data_Types/)
*Memory management, standard data types (INT, REAL, BOOL), and tag naming conventions.*

### [Chapter 7: PLC Programming](./7_PLC_Programming/)
*Hands-on logic development using Ladder Logic (LAD) and Structured Control Language (SCL).*

### [Chapter 8: Introduction to Timers and Counters](./8_Timers_and_Counters/)
*Mastering time-delay operations and event-based counting for production lines.*

### [Chapter 9: Libraries and GSD Files](./9_Libraries_and_GSD_Files/)
*Standardizing code with Global Libraries and integrating 3rd-party hardware via GSDML.*

## 🚀 Getting Started
1. **Watch the Lectures:** Follow the [PLC Training Playlist](https://www.youtube.com/playlist?list=PLFJaTiahcrM8lWGpyX2EzdxqexAtJTG9T) on YouTube.
2. **Clone the Repo:** Download these files to follow along with the hardware configurations and code samples.
3. **Software:** Ensure you have TIA Portal (V16 or higher) installed to open the `.zap` (compressed) project files.
