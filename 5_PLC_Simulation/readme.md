# Chapter 5: PLC Simulation (S7-PLCSIM)

## Overview
Simulation is a safety-critical skill. This chapter teaches how to use S7-PLCSIM to validate logic, HMI screens, and math functions without requiring physical hardware.

## Learning Objectives
* **PLCSIM vs. PLCSIM Advanced:** Understanding virtual Ethernet adapters and TCP/IP communication.
* **Simulation Tables:** Creating trigger conditions to test how logic reacts to specific sensor inputs.
* **Sequence Testing:** Using "Sim Tables" to mimic a machine's mechanical cycle.

## Pro-Tip for Students
Always ensure your PG/PC Interface is set to "PLCSIM" or "S7ONLINE" to allow TIA Portal to "see" the virtual controller.
