# Chapter 1: Introduction to Programmable Logic Controllers (PLC)

## Overview
This chapter establishes the foundational knowledge required for Industrial Automation. We move beyond simple switches to discuss how the "Industrial Brain"—the PLC—manages complex logic, safety, and data in a manufacturing environment.

## Learning Objectives
* **The Evolution of Control:** Transitioning from Hardwired Relay Logic to Software-based Control.
* **The Scan Cycle:** Detailed look at Input Image Table, Program Execution, Output Image Table, and Housekeeping.
* **Hardware Form Factors:** Differentiating between Compact (fixed I/O) and Modular (expandable) systems.

## Key Technical Concepts
* **Determinism:** Why PLCs are used instead of standard PCs (Real-time OS vs. General Purpose OS).
* **Reliability:** Electrical isolation (Opto-couplers) and industrial hardening (IP ratings).
* **Signal Flow:** Understanding how a physical 24VDC signal becomes a Boolean `1` in memory.
