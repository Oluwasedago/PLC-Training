# Chapter 9: Libraries and GSD Files

## Overview
To scale an automation project, you must use libraries. This chapter covers how to standardize your code and how to integrate non-Siemens hardware using GSDML files.

## Learning Objectives
* **Global Libraries:** Creating a company-standard library for reusable blocks and HMI icons.
* **GSD/GSDML Installation:** Importing "drivers" for VFDs, Sensors, and Remote I/O from other manufacturers.
* **Version Management:** How to update a library block and roll out changes across multiple projects.

## Hardware Integration
You will learn how to navigate the "Other Field Devices" section of the hardware catalog after installing a GSD file.
