# Chapter 7: PLC Programming - IEC 61131-3 Standards

## Overview
Programming is the heart of the course. We adhere to the international IEC 61131-3 standard, ensuring your skills are transferable across different PLC brands.

## Learning Objectives
* **Ladder Logic (LAD):** The visual representation of electrical circuits.
* **SCL (Structured Control Language):** A high-level, Pascal-based language ideal for math and data handling.
* **Code Blocks:**
    * **OB (Organization Blocks):** Managing the CPU execution.
    * **FC (Functions):** Stateless blocks for repetitive tasks.
    * **FB (Function Blocks):** Blocks with "memory" via Instance Data Blocks.

## Programming Ethics
"Write code for the person who has to fix it at 2 AM." Use comments, consistent indentation, and logical grouping.
